# Library Management System (Java)

## Overview

This project is a console-based Library Management System developed using Java. It demonstrates core programming concepts such as Object-Oriented Programming (OOP), exception handling, and collection frameworks. The system allows users to manage books efficiently through a menu-driven interface.

## Features

* Add new books
* View all available books
* Search for a book by ID
* Issue a book
* Return a book
* Input validation using exception handling

## Technologies Used

* Java
* Object-Oriented Programming (OOP)
* ArrayList (Collection Framework)
* Exception Handling
* Scanner Class for User Input

## Project Structure

```
LibraryManagementSystem.java
```

The project contains:

* Book class → Represents book details
* Library class → Manages book operations
* Main class → Handles user interaction and menu

## How to Run

### Step 1: Compile the program

```
javac LibraryManagementSystem.java
```

### Step 2: Run the program

```
java LibraryManagementSystem
```
