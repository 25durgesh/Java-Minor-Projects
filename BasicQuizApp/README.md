# Advanced Quiz Application (Java – Array Based)

## 📌 Project Description
The **Advanced Quiz Application** is a console-based Java program developed using **arrays and core control structures**.  
It allows users to attempt a multiple-choice quiz, validates inputs, calculates scores, and displays detailed results at the end.

This project is designed for beginners who have learned **Java till Arrays** and want to build logic-oriented real-world applications.

---

## 🎯 Features
- User name input
- Multiple-choice questions
- Input validation (only a/b/c/d allowed)
- Automatic score calculation
- Pass / Fail result
- Percentage calculation
- Answer summary at the end

---

## 🧠 Concepts Used
- 1D & 2D Arrays
- Loops (`for`, `while`)
- Conditional statements (`if-else`)
- `Scanner` class for user input
- Basic input validation logic

---

## 🛠️ Technologies Used
- **Language:** Java  
- **IDE:** VS Code / IntelliJ / Eclipse  
- **Java Version:** Java 8 or above
